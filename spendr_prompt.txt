### 6. Ask Spendr Page — `/dashboard/ask`

AI chat interface — same functionality as the WhatsApp bot but inside the dashboard.

**Layout**
- Full height chat interface
- Messages bubble left (user) and right (Spendr) style
- Spendr messages have a small sparkle/AI icon

**Input bar (bottom, sticky)**
- Text input: "Ask anything about your spending..."
- Send button (blue)
- Below input: 4 suggestion chips the user can tap:
  - "Where did my money go this month?"
  - "What are my subscriptions?"
  - "How does this month compare to last?"
  - "What's my biggest expense category?"

**AI behaviour**
- On send: call Claude API (POST /api/ask) with the user's message + last 3 months of transaction summary as context
- Stream the response back token by token
- Claude should answer in plain conversational Hindi-English (Hinglish is fine) with actual rupee figures from the data
- Show a typing indicator while streaming

**API route to build: `/api/ask`**
- Receives: { message: string, userId: string }
- Fetches last 90 days of transactions from Supabase for that user
- Builds a context string summarising spend by category, top merchants, subscriptions, month totals
- Sends to Claude API: system prompt = "You are Spendr, a friendly Indian personal finance assistant. Answer questions about the user's spending in plain language using the data provided. Use ₹ for amounts. Be concise, friendly, and conversational. Hinglish is welcome."
- Streams response back to client

## Additional Implementation Notes

- Use Next.js app router. All dashboard pages are under `/dashboard` and protected by a layout that checks Supabase auth session.
- For development/demo mode: if no auth session exists, auto-load the demo user (hardcoded UUID) so the app works without login during showcase.
- All Supabase queries should use the user's ID from session (or demo UUID).
- The `/api/ask` route uses the Anthropic SDK. Model: claude-sonnet-4-20250514. Max tokens: 1000. Stream: true.
- Mobile responsive — dashboard collapses to single column below 768px. Bottom nav bar on mobile with 5 icons.
- All loading states: skeleton loaders (dark grey animated pulse) not spinners.
- Empty states: friendly message + icon if no transactions found.
- Toasts for success/error actions (save note, update category, export CSV).
